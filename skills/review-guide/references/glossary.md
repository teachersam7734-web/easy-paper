# Review Guide craft glossary

| Term | Meaning |
|---|---|
| 80/20 | The 20% of the paper's content that carries about 80% of its exam value |
| Exam weight | 2×Centrality + 2×Testability + Confusability + Transferability (6 to 18) |
| Stars | ★★★ 16 to 18, ★★ 12 to 15, ★ 9 to 11; 8 or below is cut |
| Must-know | A ranked item that earns its own chunk or card |
| The one thing | The paper's message in at most 30 words |
| Memory hook | Acronym, contrast, number, image, story or classroom example that makes an item stick |
| Don't mix these up | A contrast box for confusable items |
| Blind recall | Redrawing or explaining from memory before checking |
| Game plan | The 120-minute schedule for a reader starting from zero |
| Sheet | One fixed A4 page in the renderer; exactly 4 per guide |
