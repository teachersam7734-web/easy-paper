# CC Specialist source files (main reference for Critique mode)

Copied unchanged from the user's CC Specialist skill. Critique mode *thinks* exactly like the CC Specialist
(mindset, fairness filter, Feature-Anchor-Effect strengths, Claim-Evidence-Consequence-Alternative weaknesses)
but *writes* differently: speakable cards instead of a 1,000-word essay. See ../cc-adaptation.md for the mapping.

| File | Use in Critique mode |
|---|---|
| mindset.md | Read first. The Judge's habits of mind and tone |
| pipeline.md | The 14-step CC manual; the Judge runs steps 1, 4-9 and 13 |
| brainstorm-bank.md | Angle generators, genre bank, aspect prompts, Applied Linguistics angles |
| template.md | Slot phrases; the Coach borrows Opener/Pivot/Verdict frames for spoken lines |
| humanizer.md | Red/amber lists and tells; applies to say-it lines too |
| exemplar-cc.md | Calibration of density and fairness |
| cc_lint.py | Optional: lint a prose CC if the user also wants the classic written version |
