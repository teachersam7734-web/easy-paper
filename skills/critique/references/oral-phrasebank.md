# Oral phrasebank for Critique Notes (spoken register)

Built from the CC template's fixed expressions, re-cut for speech: shorter, front-loaded, one idea per line. Never chain stock phrases, and vary them across papers.

## Opening (what the paper is)
- "This is a [review / position paper / quasi-experiment] that asks one question: X."
- "In short, the authors argue that X."
- "The paper's job is to X, so that's the yardstick I'll use."

## Signposting the structure
- "Two things it does well, and three it doesn't."
- "First, the strengths."  /  "Now the problems, starting with the biggest."
- "Last, and more minor..."

## Strengths (Feature, Anchor, Effect)
- "Its main strength is X. You can see it on page N, where Y. That matters because Z."
- "What it does really well is X."
- "A second strength: X. Table N makes this concrete."
- "This is useful for [teachers / novice researchers / reviewers], because X."

## Weaknesses (credit first, then Claim, Consequence, Fix)
- "To be fair, they do mention X on page N. But they never Y."
- "The biggest problem is X."
- "The claim that X goes further than the evidence. The data are only Y."
- "That matters for their own aim, which was X."
- "A simple fix would be X: a table, a second example, one paragraph on Y."
- "This is a minor point, but X."

## Verdict
- "On balance, it's a useful [map / starting point / model], but not the last word on X."
- "I'd recommend it for X, read alongside Y."
- "The strengths outweigh the weaknesses, as long as you remember X."

## Handling follow-ups
- Buy time: "Good question. The short answer is X."
- Answer first: "Yes, partly. Here's why: X."
- Don't know: "The paper doesn't say. My guess is X, and that's exactly the gap I mentioned."
- Pushback: "That's fair. I'd still say X, because the paper itself says Y on page N."

## Memory hooks for the order
- Name each weakness in 1 to 3 words and make an acronym or a sequence ("Sample, Method, Hype" makes SMH).
- Tie strengths to a gesture or image ("one hand: map, the other: voices").
