# Vocab Treasure glossary

| Term | Meaning |
|---|---|
| Treasure | A C1-C2 item worth reusing in one's own academic writing |
| Reel | One paper's Vocab Treasure pages in the booklet |
| Feature card | The single most valuable entry on a sheet, shown full width |
| In context | The verbatim line from the paper that shows the item in use |
| Alternatives | Near-synonyms or rephrasings, ordered by closeness |
| Pattern | The grammar frame or typical collocates of the item |
| Treasure Chest | The cumulative, deduplicated bank of all entries across papers (CSV + Markdown) |
| Collocation | Words that habitually co-occur (*conduct* research, not *do* research) |
| Lexical bundle / formula | A recurrent multiword sequence in academic prose (*on the other hand*, *the extent to which*) |
| Hedge | A device that softens a claim's certainty |
| Reporting verb | A verb used to attribute ideas to sources (*contend*, *posit*, *concede*) |
