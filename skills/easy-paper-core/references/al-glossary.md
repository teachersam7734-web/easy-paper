# Applied Linguistics core glossary (plain words)

Use these glosses, adapted to the paper's own definitions where they differ. The paper's own wording always wins for verbatim definitions. Arranged by area. "See" points to a field file.

## SLA theory
| Term | Plain gloss |
|---|---|
| Acquisition vs learning | Krashen's split: picking a language up without noticing it vs studying its rules consciously (see Krashen) |
| Comprehensible input | Language you can understand, often thanks to context, that is slightly above your level |
| i+1 | Input just one step beyond your current level |
| Affective filter | Anxiety or low confidence that blocks input from being taken in |
| Intake | The part of input the learner actually processes |
| Noticing | Consciously registering a feature of the input; for Schmidt, the door to learning |
| Noticing the gap | Seeing the difference between what you said and what a proficient speaker says |
| Interaction Hypothesis | Conversation helps learning when people negotiate meaning and get feedback (see Long) |
| Negotiation for meaning | Back-and-forth checks ("Sorry, you mean...?") that repair a communication breakdown |
| Output Hypothesis | Having to produce language pushes learners to notice gaps and test hypotheses (see Swain) |
| Pushed output | Speaking or writing that stretches the learner beyond what is easy |
| Languaging | Using language to think about language, often aloud with a peer |
| Interlanguage | The learner's own developing language system, with its own rules |
| Fossilization | When parts of an interlanguage stop developing |
| Transfer | Influence of the first language (or another language) on the new one |
| Explicit vs implicit knowledge | Knowledge you can state and use with effort vs knowledge you use automatically without awareness |
| Automatization | Practice turning slow, effortful knowledge into fast, fluent use |
| Usage-based approach | Language is learned from frequent patterns met in use, not from innate rules |
| Sociocultural theory (SCT) | Learning starts between people (mediated by tools, talk, others) and moves inward (see Lantolf) |
| ZPD | Zone of proximal development: what a learner can do with help but not yet alone |
| Scaffolding | Temporary, adjustable help that is withdrawn as the learner improves |
| Mediation | Using tools, signs or people to control one's thinking and activity |
| Complex dynamic systems (CDST) | Language and learners change in non-linear, interconnected ways, so variation is data (see Larsen-Freeman) |
| Communicative competence | Knowing how to use a language appropriately, not just correctly (see Canale & Swain) |

## Instruction and feedback
| Term | Plain gloss |
|---|---|
| Instructed SLA (ISLA) | The study of how teaching affects second language learning |
| Focus on form (FonF) | Brief attention to a language form during meaning-focused activity |
| Focus on forms (FonFs) | Teaching forms one by one as the main content of lessons |
| Form-focused instruction | Any teaching that draws attention to form, planned or incidental |
| TBLT | Task-based language teaching: lessons built around meaningful tasks, not grammar points |
| Corrective feedback (CF) | Any response that signals a learner's utterance or text has an error |
| Recast | Repeating the learner's utterance correctly without saying it was wrong |
| Prompt | Feedback that pushes the learner to self-correct (elicitation, clarification request, metalinguistic clue, repetition) |
| Uptake | The learner's immediate response to feedback |
| Repair | Uptake that actually corrects the error |
| Written corrective feedback (WCF) | Feedback on errors in writing: direct, indirect, metalinguistic, focused or unfocused |
| Automated writing evaluation (AWE) | Software that scores or gives feedback on writing |
| Washback | The effect of a test on teaching and learning |

## Individual differences
| Term | Plain gloss |
|---|---|
| L2 Motivational Self System | Motivation as the ideal L2 self (who I want to be), the ought-to L2 self (who others expect), and the learning experience (see Dörnyei) |
| Willingness to communicate (WTC) | Readiness to speak in the L2 when given the chance |
| Foreign language anxiety | Worry and tension specific to using or learning a foreign language |
| Foreign language enjoyment | Positive emotion from L2 learning; part of positive psychology in SLA |
| Engagement | Behavioural, cognitive, emotional and social involvement in learning |
| Self-efficacy | Belief that you can succeed at a specific task |
| Aptitude | Talent for learning languages (memory, sound coding, grammatical sensitivity) |

## Research methods
| Term | Plain gloss |
|---|---|
| Paradigm | A research community's shared beliefs about reality, knowledge and method (Kuhn) |
| Positivism / postpositivism | One reality that can be measured; postpositivism adds that measurement is fallible |
| Constructivism | Reality is built by people's meanings, so it is studied from the inside |
| Pragmatism | Judge methods by what works for the question, not by loyalty to a camp |
| Incompatibility thesis | The claim that qualitative and quantitative paradigms cannot be mixed |
| Mixed methods | Combining qualitative and quantitative approaches in one study or program |
| Triangulation | Checking a finding with more than one method, source, researcher or theory |
| Convergent / explanatory sequential / exploratory sequential | Mixed designs: both strands together; QUAN then QUAL to explain; QUAL then QUAN to build or test |
| Meta-inference | A conclusion drawn by integrating qual and quan results |
| Validity | Whether the conclusions you draw from scores or data are justified |
| Internal validity | Whether the treatment, not something else, caused the effect |
| External validity / generalizability | Whether the results hold beyond this sample and setting |
| Reliability | Consistency of a measure (for example Cronbach's alpha, inter-rater agreement) |
| Trustworthiness | Qualitative quality: credibility, transferability, dependability, confirmability |
| Quasi-experiment | An experiment without random assignment (often intact classes) |
| Effect size | How big a difference or relationship is (Cohen's d, r), not just whether it exists |
| Statistical significance (p) | How surprising the data would be if there were no real effect; not the size of the effect |
| Thematic analysis | Coding qualitative data and grouping the codes into themes |
| Systematic review | A review with a stated search, inclusion criteria and appraisal |
| Meta-analysis | Statistically pooling effect sizes across studies |
| Replication | Repeating a study to see whether the result holds |
| Construct | The abstract ability or trait a study tries to measure (for example motivation, writing quality) |
| Operationalization | Turning a construct into something observable and measurable |

## Technology and AI in language education
| Term | Plain gloss |
|---|---|
| CALL | Computer-assisted language learning |
| Normalisation (Bax) | When a technology is so ordinary in teaching that nobody notices it |
| TAM | Technology Acceptance Model: people adopt tools they find useful and easy |
| TPACK | Teachers' blend of technological, pedagogical and content knowledge |
| Generative AI (GenAI) | AI that produces new text, images or audio (for example ChatGPT) |
| Large language model (LLM) | A very large AI model trained on text to predict and generate language |
| Hallucination | Confident AI output that is false (fake facts, fake references) |
| AI-text detector | A tool that estimates whether text was written by AI; known for false positives |
| AI-assisted plagiarism | Submitting AI-generated or AI-paraphrased work as one's own without acknowledgement |
| Academic integrity | Honesty and transparency in producing and reporting academic work |
| AI literacy | Knowing how AI works, where it fails, and how to use and question it responsibly |
