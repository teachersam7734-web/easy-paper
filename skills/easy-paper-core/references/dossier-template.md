# Paper dossier template (built once by the Analyst, read by every persona)

Save as `<workspace>/dossier.md`. Every fact carries a printed-page anchor. Mark anything you inferred as `(inferred)`. This file is the single source of truth for later stages, so it must be accurate, not pretty.

```markdown

- Year / venue / volume(issue) / pages / DOI:

- Section label printed on the paper (Article, Review, Chapter, Editorial...):

## 1. Genre and yardstick
- Genre (see paper-genres.md):

- Scope statements and declared exclusions (quoted with page):
```

Rules: quote purpose statements, research questions and definitions exactly. Paraphrase everything else. Never pad a section; write "none" when the paper has none (for example, no limitations section). A documented absence is itself useful data.
